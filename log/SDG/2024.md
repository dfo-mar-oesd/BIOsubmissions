## May 2024 Status

### Pipeline Status

### Current Bugs and Issues

#### 1. Depth Variable Metadata

**Problem:** Depth variable metadata not being populated automatically
- Fields missing: `DEPTH_SAMPLING` and `units`

**Workaround:** 
- Manually input as:
  - Variable name: `DEPTH_SAMPLING`
  - Units: `m`

**Solution Needed:**
- Update pipeline to set default values for depth metadata
- Should automatically populate during conversion

#### 2. Variable Mapping Issues

**Problem:** Not all variables are mapping properly
- **Result:** Duplication of `SALNTY` and `CTDTMP`
- Variables appearing twice in output

**Action Needed:**
- Review variable mapping configuration
- Fix duplicate mapping rules
- Test with sample data to verify fix

#### 3. Flag Parsing

**Problem:** Flags are not being parsed by SDG platform
- Data contains quality flags but platform doesn't recognize them

**Possible Solutions:**
- Adjust flag column naming convention
- Review SDG platform flag format requirements
- May need to modify flag format in conversion pipeline
